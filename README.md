# Electric-Vehicle-Market

# Electric Vehicle Market Performance & Insights

An analytical dashboard project focusing on the global Electric Vehicle (EV) market landscape, market trends, performance metrics, and key data insights.

---

## 📌 Project Overview

This repository contains data visualizations and analytical files analyzing the growth, adoption, and performance metrics of the Electric Vehicle market. The goal of this project is to highlight key market drivers, manufacturer trends, and consumer adoption rates across different regions.

---

## 📂 Repository Contents

- **`Electric Vehicle Market Performance & Insights Dashboard.twbx`**  
  An interactive Tableau Packaged Workbook containing full data dashboards, interactive filters, and visual insights into EV market performance.
- **`README.md`**  
  Project overview and setup documentation.

---

## 📊 Key Insights & Dashboard Features

- **Market Growth & Trends:** Visualizing year-over-year EV adoption rates.
- **Manufacturer Performance:** Breakdown of top market players, vehicle types, and model performance.
- **Regional Analysis:** Geographical distribution and market penetration of electric vehicles.
- **Interactive Metrics:** Key Performance Indicators (KPIs) monitoring market share and growth trajectories.

---

## 🛠️ Tools & Technologies Used

- **Data Visualization:** Tableau Desktop / Tableau Reader (`.twbx`)
- **Version Control:** Git & GitHub
